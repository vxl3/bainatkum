# بيناتكم 👀

«مو كل صديق يعرفك صدگ» — لعبة تحديات عراقية بين الأصدقاء.

## حالة المشروع
هذا المستودع قيد البناء على مراحل. المرحلة الحالية: المرحلة الأولى (الهيكل الأساسي + الصفحة الرئيسية).
باقي المراحل (قاعدة البيانات، إنشاء التحديات، تجربة اللعب، بطاقة النتيجة، النشر) قادمة لاحقاً.

## التشغيل محلياً

npm install
npm run dev

افتح http://localhost:3000

## متغيرات البيئة
انسخ .env.example إلى .env.local واملأ القيم الحقيقية لاحقاً عند إعداد Supabase:

- NEXT_PUBLIC_SUPABASE_URL
- NEXT_PUBLIC_SUPABASE_ANON_KEY
- SUPABASE_SERVICE_ROLE_KEY (خادم فقط، لا يُستخدم بالمتصفح)
- NEXT_PUBLIC_SITE_URL

## المراحل القادمة
2. قاعدة البيانات (Supabase) وسياسات الأمان.
3. إنشاء التحديات وروابطها.
4. تجربة الصديق وحساب النتائج.
5. بطاقة النتيجة والمشاركة.
6. الاختبارات.
